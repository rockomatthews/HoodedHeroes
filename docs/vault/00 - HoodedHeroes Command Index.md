## Rules that do not drift

- The society has exactly 3,000 Genesis HoodedHeroes.
- `$HERO` has a fixed one-billion supply and no future mint path.
- Holding 25,000 HERO previews the society; owning a HoodedHero unlocks its private utilities.
- Community code enters protected branches only through isolated tests, signed pull requests, review, and security approval.
- Mainnet deployment, live sales, listings, promotions, and Stock Token activity require separate approval.
