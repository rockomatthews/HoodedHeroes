# Contributing to Launch Bay

Launch Bay is AGPL-3.0-or-later and pull-request-only. Contributions must be original or license-compatible; do not paste competitor source code into this repository.

## Required evidence

- A narrowly scoped problem statement and linked Code Bazaar bounty.
- Tests that fail before and pass after the change.
- `pnpm lint`, `pnpm typecheck`, `pnpm test`, and the relevant Foundry or Solana test transcript.
- Reproducible build hash and generated SBOM when the sandbox supports them.
- Security-impact note covering custody, authority, supply, refunds, fees, vesting, liquidity, metadata identity, and replay behavior.
- Signed commit and `Signed-off-by` DCO line.

Mainnet configuration, deployment, listing submissions, paid promotion, custody, and secrets never belong in community pull requests.
