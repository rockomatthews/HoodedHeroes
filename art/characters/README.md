## Prompt direction

Each v1 prompt requested an isolated, original full-body hooded hero in the first concept's screen-printed pop-comic language: black face void, narrow glowing eyes, thick imperfect ink, sharp cream highlights, halftone texture, heavy boots, one signature power effect, and one dominant accent color. Existing comic franchises and Robinhood branding were explicitly excluded.

The v2 background-extraction pass preserved the design and removed only the backdrop. The website copies are in `apps/web/public/heroes/`.
