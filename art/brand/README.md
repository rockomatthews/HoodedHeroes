# HOODED coin emblem

`hooded-coin-emblem-v1.png` is the first accepted circular site emblem and coin-logo direction.

Built-in image-generation prompt:

> Create a perfectly round saturated-yellow coin with a thick irregular black ink rim, centered minimalist black hood silhouette, deep black face void, two sharp paper-cream eyes, and a tiny cream rim highlight. Use the supplied screenshot as the strict subject reference and the HOODED entry concept as the pop-comic texture reference. Preserve a genuinely transparent background outside the circle. Include no rectangle, text, currency symbol, external brand mark, or existing comic-franchise resemblance.

The production copy is stored at `apps/web/public/brand/hooded-coin-emblem.png`; `apps/web/app/icon.png` supplies the browser/site icon.
